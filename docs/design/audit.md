## P0 · 必须先修

### P0-01 竖屏标题的主按钮被裁切，新玩家难以开始游戏
- 证据：`11-mobile-portrait-title.png`。390px 宽竖屏下 scale 被宽度限制，舞台约 219px 高。标题卡 `max-height: calc(100% - 16px)` 以舞台为上限，导语和原创声明占满卡片，「继续旅程 / 新的旅程」落在折线下方。卡片虽 `overflow: auto`，但没有滚动条样式或「向下看」的提示；触控十字和动作键还顶在卡片下沿。
- 影响：第一屏看不见开始游戏的主 CTA。旧审计「竖屏标题被裁」机制已变（不再是 16:10 拉伸裁字），**问题本身复核后仍在**。
- 修改要求：按设计系统 §9.5 执行。标题 / 帮助 / 确认卡挂在 `#app`，相对于视口，`max-height: calc(100dvh - touchH - 24px)`；标题态隐藏虚拟键，此时 `touchH = 0`。主 CTA 钉在卡片底部，正文再长只滚中段。标题改为「翠谷奇谭」。
- 验收：在 390×844 竖屏与 844×390 横屏，**不滚动**即可看见「继续旅程」「新的旅程」（或确认框的是 / 否）；声明过长不得把按钮挤出首屏。

### P0-02 横屏把 16:9 舞台收成「邮票」，可读性崩溃
- 证据：`13-mobile-landscape-ingame.png`、`14-mobile-landscape-title.png`。只要 `body.touch`，高度就先预留 168px。横屏短边扣完后 scale ≈ 0.82，画布只有约 394×222 CSS 像素，居中挤在大块空白中。HUD 和技能圆钮相对过大。
- 影响：横屏本应是手机上最好的游玩方向，现在战场最小、控件最大。旧审计「舞台过小」**复核后保留**。
- 修改要求：按设计系统 §9.2–§9.4 改 `resize()`。**禁止先扣 `TOUCH_H_MAX 168` 再算 scale**。先按 `TOUCH_H_MIN 72` 给舞台让路，再把剩余高度 `clamp` 到 72–168 作为触控高。横屏触控默认仍在舞台下。左右收键只允许在舞台仍低于 `STAGE_H_MIN 180` 时作为退化。不要把舞台拉成非 16:9。
- 验收：在 844×390 横屏，舞台 CSS 高度 ≥ 270（约 1×，允许 1–2px 取整误差），触控在舞台外且高度 ≤ 168、≥ 72；画面不拉伸。用 568×320 一类更矮横屏复查：舞台不得低于 180，触控可压缩到 56 或进入左右退化。

### P0-03 触控 / 窄屏 HUD、提示条、技能钮互相重叠
- 证据：`12-mobile-portrait-ingame.png`、`13-mobile-landscape-ingame.png`。截图里「芽芽 · 露珠镇」折成两行，撞上等级徽章；提示横在场景中部；右下四颗技能钮盖住地面；右上四钮压住建筑。
- 影响：看不清角色和 NPC，也容易误点。旧审计**复核后保留**。
- 修改要求：按设计系统 §9.6。HUD 不写主角名（不要「芽芽」），只保留地图名（如「露水镇」），单行省略。舞台 CSS 高度 < 270 或触控可见时：提示放到舞台外或缩成单行；隐藏舞台内技能圆钮（或改为不可点状态灯）。右上控件不得挡住铃兰。
- 验收：390×844 竖屏与 844×390 横屏的游戏中画面，姓名/地图行不折行撞徽章，提示不挡角色，技能区与铃兰、传送门名牌不重叠；界面无「芽芽」「露珠镇」「青苔野径」等旧名。

### P0-04 林地右侧地面 / 近景出现黑色矩形缺口，压住技能栏
- 证据：`09-wild.png`。地面纹理在画面右侧被竖切开，下方实心填充变成一块近黑矩形，技能圆钮压在这个洞上。不像设计好的深坑（该镜头不应看到 x≈800 的缺口）。
- 影响：破世界可信度，并把主操作区衬在黑底上。
- 修改要求：修平铺 / 裁切，保证 `GROUND_FILL` 与地面条、近景一直铺到视图右缘。
- 验收：在原机位（玩家约 x=500 的翠叶林地）重截，右缘无黑色矩形，技能栏下是完整地面或合法填充色。

### P0-05 标题与帮助态仍露出整套战斗虚拟键
- 证据：`11-mobile-portrait-title.png`、`14-mobile-landscape-title.png`。`body.touch` 时 `#touch` 无条件显示。
- 影响：加重 P0-01，第一印象像已经打到一半。
- 修改要求：仅 `play`（及确实需要移动的状态）显示虚拟键；`title` / 帮助展开 / `confirm` 时隐藏。
- 验收：同上两个标题视口，战斗十字和动作键不可见；进入游戏后出现，回标题后消失。

## P1 · 明显损害体验，应在下一次迭代修

### P1-01 打开商店 / 背包 / 暂停 / 死亡 / 胜利时没有模态遮罩
- 证据：`03-shop.png`、`04-inventory.png`、`05-pause.png`、`07-death.png`。卡片叠在仍全亮、仍在动的场景上；右下技能钮还在。`mode !== play` 时 hint 会隐藏，这一项保持。
- 旧审计**复核后保留**。
- 修改要求：弹层打开时加 40–50% 奶油墨遮罩，忽略技能钮点击，并暂停场景喧闹。
- 验收：打开上述任一面板时，舞台明显变暗，点技能钮无效果；关闭后面板与遮罩一起消失。

### P1-02 没有独立对话 UI，对白直接变成商店
- 证据：`03-shop.png`。当时和 NPC 互动立刻出现商店，没有立绘对白。主线《翠谷奇谭》有铃兰对话；`visual-style.md` 也写了底部对话条。
- 修改要求：互动先出铃兰对白（头像 + 名牌「铃兰」+ 正文，可打字机也可整段出现），再给「看看货」进入商店。不要保留「互动即开店」。文案用翠谷主线对白，不用「果果婆婆的小摊」。
- 验收：靠近铃兰点互动，先看到对话；从对话能进商店、能关闭回到场景；全程名称是「铃兰」。

### P1-03 击败 Boss 只有 toast，没有胜利结算
- 证据：`08-victory-toast.png`、`08b-victory-reward.png`。当时 toast 写「雾核兽散成了一片萤光」，商店谢礼句仍像战前日常。公开主线已有胜利结算，合入时要保留/恢复，不能只留 toast。
- 修改要求：击败磐苔巨像后弹出可关闭结算卡（Boss 名、掉落、经验）。用 `bossDefeated` 切换铃兰对白。所有文案用「磐苔巨像 / 幽苔洞窟 / 露珠」，不得再出现雾核兽、萤根洞窟。
- 验收：击倒 Boss 后有结算卡，关闭后可继续；再找铃兰，对白已变为战后内容；界面无旧 Boss 名。

### P1-04 升级只有 toast，没有升级横幅 / 卡片
- 证据：`06-levelup.png`。只有顶条 toast，没有停留式展示。
- 修改要求：升级卡或画布横幅，列出新的生命 / 魔力 / 攻击上限，停留到玩家关闭。
- 验收：升级时出现可关闭的升级信息，数字与实际属性一致；不会一闪而过只能靠 toast。

### P1-05 地面下方的实心填充条过高，成为一块「死色带」
- 证据：`02-town.png`、`09-wild.png`、`10-cave-boss.png`。填充常占画面下 1/3。
- 修改要求：降低实心带、用 tile 底 40% 重复，或加一层浅浅的土截面 / 碎石，避免整块纯色。
- 验收：三张地图的地面下都看得到截面或重复纹理，而不是一条高高的平涂色带。

### P1-06 Boss 条的名称胶囊压住血条和数字
- 证据：`10-cave-boss.png`。当时名牌写「雾核兽」，叠在条中央，血量对比不足。
- 修改要求：名牌上移 8–10 逻辑像素，文字改为「磐苔巨像」；数字改奶油色 + ink 描边。
- 验收：名称完整在条上方，不挡条、不挡数字；对比足够。

### P1-07 标题卡在镇上会挡住 NPC 名牌
- 证据：`01-title.png`。卡片盖住当时的「果果婆婆」名牌。
- 修改要求：标题态用预置摄像机、隐藏名牌与 HUD，或把卡片移出舞台（与 P0-01 一起做）。舞台上若露出 NPC，名牌应为「铃兰」且不被挡。
- 验收：标题画面看不到残缺名牌，也不露出旧名。

### P1-08 静音按钮在图标上叠了「音」字
- 证据：`02-town.png` 右上。
- 修改要求：去掉「音」字，用 `aria-label`（声音开 / 声音关）和 `aria-pressed`。
- 验收：钮上只有喇叭图；读屏能区分开与关。

### P1-09 触控下快捷栏仍显示键盘键帽
- 证据：`12-mobile-portrait-ingame.png`。圆钮右下角仍是 L / U / Q / E。合入主线后键位默认改为 Enter / U / I / H / G，但触控下同样不应显示键帽。
- 修改要求：`body.touch` 隐藏键帽；触控判定以 `pointer: coarse` 为主。桌面键盘提示须与最终键位一致。
- 验收：手机游戏中看不见 L/U/Q/E 或 Enter 等键帽；桌面页脚与帮助列出的是实际键位。

### P1-10 开场引导在错误地图残留，页脚文案未统一
- 证据：`10-cave-boss.png` 出现镇上开场句「往右走，光门通往青苔野径」（当时文案）。切图不清理 `greet`。
- 修改要求：`enterMap`（或主线等价切图函数）时清掉开场计时；hint 跟当前地图走，用地图的翠谷名（露水镇 / 翠叶林地 / 幽苔洞窟）。页脚键盘说明在触控下隐藏，桌面写「按 Enter 互动」。
- 验收：在开场 8 秒内切到林地或洞窟，不再出现「往右走，光门通往……」的镇上句；全文无「青苔野径」等旧名。

### P1-11 林地近景草丛可能把主角吃掉
- 证据：`09-wild.png` 中小怪清楚，主角几乎无法辨认。
- 修改要求：近景默认画在实体后；保证主角描边在草丛前仍能读出剪影，或降低近景遮挡区 alpha。
- 验收：同一机位能清楚认出主角。

### P1-12 暂停页过瘦，缺少说明和声音入口
- 证据：`05-pause.png`。旧审计**复核后保留**。
- 修改要求：暂停内提供操作说明（键位与触控各一版）和静音入口。
- 验收：不必回到标题就能看到操作说明并开关声音。

### P1-13 无存档时「继续旅程」仍占一颗主按钮
- 证据：`01-title.png`。旧审计**复核后保留**。注意：只有 `cuigu-qitan-save-v2` 才算新版存档，有 v1 旧档时不得把它当成可继续的新档。

## P2 · 品质与规范债

### P2-01 屏幕震动被写死关闭
- Q 版 `render.js` 写死 `shake = 0`。若为避免平滑缩放发糊，在设计系统或 visual-style 写明默认关闭；否则按文档恢复，并加 `prefers-reduced-motion`。
- 验收：要么受击 / Boss 砸地有衰减震动且减动效偏好下关闭，要么文档明确「默认关闭」。

### P2-02 冷却表现与文档不符
- 文档：圆锥扫光 + 剩余秒。实现：高度遮罩，无秒数。选定一种，改代码或改 `docs/design/design-system.md`，两者一致。
- 验收：技能冷却的视觉与设计系统描述一致；能看出剩余冷却。

### P2-03 标题描边与四字标题
- 现实现 2px 描边、无奶油内光。设计系统已定稿：先用 2px，四字标题 44–52px（窄屏 32–36px），不要盲目加到 6px 导致汉字被吃瘦。
