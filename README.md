# 翠谷奇谭 · Tale of the Verdant Vale

一款原创的 2D 横版闯关动作 RPG 网页游戏。纯 HTML + CSS + 原生 JavaScript（ES Modules），
零运行时依赖。画面为 480×270 逻辑舞台上的 Q 版位图贴图，平滑缩放 + 16:9 letterbox，
UI 为奶油木 + 叶绿糖果风。

> **原作声明**：本作为独立原创作品，灵感来自经典横版动作冒险，与任何商业游戏无关。
> 所有角色、怪物、地图、UI 均为原创美术（`assets/` 下位图），音效为 Web Audio 现场合成。

## 快速开始

```bash
# 安装（本项目无第三方依赖，仅生成 lockfile）
npm install --registry=https://registry.npmmirror.com

# 启动（生产模式直接可玩，无需 dev server）
npm start
# 打开 http://127.0.0.1:43125/ （端口可用环境变量 PORT 覆盖，监听 0.0.0.0）

# 运行无头测试（纯 Node）
npm test
```

服务器只用了 Node 标准库 `http` + `fs`，设置了正确的 MIME（含 ES Module 的
`text/javascript`），支持直接用 IP 或 HTTPS 反向代理访问（所有资源均为相对路径）。

## 玩法简介

- **露水镇（安全区）**：和杂货商铃兰对话、买药剂；存档水晶可手动记录；有教学告示牌与攀爬绳索。
- **翠叶林地**：多层平台 + 两根绳索，栖息着**荆刺果**（地面）与**雾羽蛾**（飞行）。
- **幽苔洞窟**：更密的平台、会伤人的尖晶石陷阱、**苔石傀儡**，深处盘踞着 Boss
  **磐苔巨像**（蓄力冲撞 + 三连孢子抛射两种攻击模式）。击败后弹出胜利结算与大量掉落；
  Boss 被击败后**不再重生**（小怪每 15 秒重生）。
- 击败怪物获得经验与**露珠**（货币），掉落药剂可走近拾取；升级回满状态并提升属性
  （每级 +18 生命 / +8 魔力 / +2 攻击，等级上限 30）。
- 倒下后会在露水镇苏醒，只损失 10% 露珠，等级与背包保留。
- 进度（等级、属性、背包、货币、所在地图与位置、Boss 是否已击败）自动存入 localStorage
  （存档键 `cuigu-qitan-save-v2`），标题界面可「继续旅程」。

## 操作方式

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | ← → / A D | 左下方向键 |
| 攀爬绳索 | ↑ ↓ / W S | 方向键 ▲ ▼ |
| 跳跃（下+跳=落下平台） | 空格 / K | 「跳」按钮 |
| 普通攻击 | J / Z | 「攻击」按钮 |
| 技能一 翠风斩（12 MP） | U 或 1 | 「翠风」按钮 |
| 技能二 晨露祝福（20 MP） | I 或 2 | 「晨露」按钮 |
| 喝生命药（优先） | H 或 3 | 「血药」按钮 |
| 喝魔力药 | G 或 4 | 「蓝药」按钮 |
| 交互（对话/传送门/存档） | Enter | 「互动」按钮 |
| 背包 | Tab 或 B | 右上背包按钮 |
| 暂停 | Esc / P | 右上 ☰ |
| 静音 | M | 右上喇叭 / 暂停面板 |

触屏按 `pointer: coarse` 判定，横屏仍保持 16:9，触控在舞台外（算法见
`docs/design/design-system.md` §9）。

## 项目结构

```
index.html            页面骨架（HUD / 面板 / 标题 / 触控层）
style.css             糖果风 UI 样式（token 与 §9 响应式）
server.mjs            极简静态服务器（Node 标准库，PORT 默认 43125）
assets/               70 张 Q 版位图（清单见 docs/design/asset-manifest.md）
src/
  main.js             入口：主循环、场景、交互、存档调度、响应式
  core/               输入 / Web Audio 音效 / 事件总线 / localStorage 封装 / 素材加载 / 布局
  logic/              可在 Node 中测试的纯逻辑：升级、战斗、背包、技能、
                      存档序列化、AABB 物理、实体与怪物 AI
  data/               地图（3 张）与怪物数值
  game/               浏览器侧流程：状态、战斗动作、玩家/怪物/世界更新
  render/             Canvas 位图绘制：背景视差、地形、角色、特效、HUD、触控、面板
test/                 无头测试（node:test）
docs/design/          设计系统、视觉审计、素材清单、合入执行清单
```

测试覆盖：升级与经验曲线、伤害/死亡/药水、背包增减与买卖（钱不够提示）、技能 MP
与冷却、存档序列化往返与脏数据回退（存档键 v2）、AABB 与平台着陆/穿落、地图与传送门完整性
（三图互连、落点合法、平台可达性、出生点不嵌地形）、怪物 AI（巡逻/追击/硬直/Boss 双模式）、
响应式布局算法（§9）。

## 已知说明

- Boss 击败后不再重生；如需再次挑战可开新档。
- 舞台固定 480×270 逻辑分辨率、16:9 letterbox，平滑缩放（不拉伸、不 nearest-neighbour）。
- 缺图会进入可重试的错误态，正式包不长期回退到代码绘制。
