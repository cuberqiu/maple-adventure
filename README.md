# 翠谷奇谭 · Tale of the Verdant Vale

一款完全原创的 2D 横版闯关动作 RPG 网页游戏。纯 HTML + CSS + 原生 JavaScript（ES Modules）+
Canvas 程序化绘制，零运行时依赖、零外部素材。

> **原作声明**：本游戏为独立原创作品，灵感来自经典横版动作冒险，与任何商业游戏无关。
> 所有角色、怪物、地图、UI、音效均由代码程序化生成（音效为 Web Audio 现场合成），
> 未使用任何第三方图片、精灵表、字体或音频文件。

## 快速开始

```bash
# 安装（本项目无第三方依赖，仅生成 lockfile）
npm install --registry=https://registry.npmmirror.com

# 启动（生产模式直接可玩，无需 dev server）
npm start
# 打开 http://127.0.0.1:43125/ （端口可用环境变量 PORT 覆盖，监听 0.0.0.0）

# 运行无头测试（纯 Node，54 项）
npm test
```

服务器只用了 Node 标准库 `http` + `fs`，设置了正确的 MIME（含 ES Module 的
`text/javascript`），支持直接用 IP 或 HTTPS 反向代理访问（所有资源均为相对路径）。

## 玩法简介

- **露水镇（安全区）**：和杂货商铃兰对话、买药剂；存档水晶可手动记录；有教学告示牌与攀爬绳索。
- **翠叶林地**：多层平台 + 两根绳索，栖息着**荆刺果**（地面）与**雾羽蛾**（飞行）。
- **幽苔洞窟**：更密的平台、会伤人的尖晶石陷阱、**苔石傀儡**，深处盘踞着 Boss
  **磐苔巨像**（蓄力冲撞 + 三连孢子抛射两种攻击模式）。击败后弹出胜利结算与大量掉落；
  Boss 被击败后**不再重生**（小怪每 15 秒重生）。
- 击败怪物获得经验与**露珠**（货币），掉落药剂可走近拾取；升级回满状态并提升属性
  （每级 +18 生命 / +8 魔力 / +2 攻击，等级上限 30）。
- 倒下后会在露水镇苏醒，只损失 10% 露珠，等级与背包保留。
- 进度（等级、属性、背包、货币、所在地图与位置、Boss 是否已击败）自动存入 localStorage，
  标题界面可「继续冒险」。

## 操作方式

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | ← → / A D | 左下方向键 |
| 攀爬绳索 | ↑ ↓ / W S | 方向键 ▲ ▼ |
| 跳跃（下+跳=落下平台） | 空格 / K | 「跳」按钮 |
| 普通攻击 | J / Z | 「击」按钮 |
| 技能一 翠风斩（12 MP） | U 或 1 | 「技1」按钮 |
| 技能二 晨露祝福（20 MP） | I 或 2 | 「技2」按钮 |
| 喝生命药（优先） | H 或 3 | 「药」按钮 |
| 喝魔力药 | G 或 4 | —（背包里可用） |
| 交互（对话/传送门/存档） | Enter | 「话」按钮 |
| 背包 | Tab 或 B | 背包面板 |
| 暂停 | Esc / P | HUD 右上 ☰ |
| 静音 | M | 标题/暂停面板勾选 |

## 项目结构

```
index.html            页面骨架（HUD / 面板 / 标题画面）
style.css             可爱风格 UI 样式（含移动端适配）
server.mjs            极简静态服务器（Node 标准库，PORT 默认 43125）
src/
  main.js             入口：主循环、场景、交互、存档调度
  core/               输入 / Web Audio 音效 / 事件总线 / localStorage 封装
  logic/              可在 Node 中测试的纯逻辑：升级、战斗、背包、技能、
                      存档序列化、AABB 物理、实体与怪物 AI
  data/               地图（3 张）与怪物数值
  game/               浏览器侧流程：状态、战斗动作、玩家/怪物/世界更新
  render/             Canvas 绘制：背景视差、地形、角色、特效、HUD、触控、面板
test/                 54 项无头测试（node:test）
```

测试覆盖：升级与经验曲线、伤害/死亡/药水、背包增减与买卖（钱不够提示）、技能 MP
与冷却、存档序列化往返与脏数据回退、AABB 与平台着陆/穿落、地图与传送门完整性
（三图互连、落点合法、平台可达性、出生点不嵌地形）、怪物 AI（巡逻/追击/硬直/Boss 双模式）。

## 已知说明

- Boss 击败后不再重生；如需再次挑战可开新档。
- 画面为固定 960×540 逻辑分辨率自适应缩放；375px 竖屏手机可正常游玩（触控按钮半透明）。
